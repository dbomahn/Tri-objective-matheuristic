# Benchmark data

Instance files will be uploaded separately. Place the paper's original MOAP and MOKP benchmark files under `original/`, and the TOFLP and TOMIPLIB files used in the computational study under `generated/`.

See [docs/instance_generation.md](../docs/instance_generation.md) for provenance and published construction descriptions. The generation scripts are unavailable; directory names do not imply that instances can be regenerated from this repository.
