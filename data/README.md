# Benchmark data

This directory separates benchmark instances generated for the paper from benchmark sets that are available externally.

- `generated/`: the TOFLP and TOMIPLIB archives used in the computational study.
- `external/`: provenance and access information for the MOAP and MOKP benchmark sets. Those files are not copied into this repository.

See [`docs/instance_generation.md`](../docs/instance_generation.md) for the benchmark provenance and construction details.
