# Generated benchmark instances

The archives in this directory contain the generated benchmark sets used in the paper.

| Benchmark | Number of instances | Archive | Instance format |
|---|---:|---|---|
| TOFLP | 120 | [TOFLP.zip](TOFLP.zip) | `.txt` |
| TOMIPLIB | 5 | [TOMIPLIB.zip](TOMIPLIB.zip) | `.lp*` |

The TOMIPLIB instances use the LP format described in the [FPBH.jl documentation](https://aritrasep.github.io/FPBH.jl/docs/build/getting_started.html#Using-LP-File-Format-1).

The archive contents and their accompanying README files are retained as supplied. See [the benchmark provenance notes](../../docs/instance_generation.md) for details of how the sets were constructed.
