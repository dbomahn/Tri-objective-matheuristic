# Generated benchmark instances

This directory contains the generated benchmark sets used in the paper.

| Benchmark | Number of instances | Archive | Format |
|---|---:|---|---|
| TOFLP | 120 | [TOFLP.zip](TOFLP.zip) | `.txt` |
| TOMIPLIB | 5 | [TOMIPLIB.zip](TOMIPLIB.zip) | LP files |

The [TOFLP README](TOFLP/README.md) documents its model, authorship, assumptions, instance naming convention and file layout. The README files supplied inside the archives are retained.

The TOMIPLIB instances use the LP format described in the [FPBH.jl documentation](https://aritrasep.github.io/FPBH.jl/docs/build/getting_started.html#Using-LP-File-Format-1).

See [the benchmark provenance notes](../../docs/instance_generation.md) for details of how the benchmark sets were constructed.
