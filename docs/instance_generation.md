# Benchmark instance provenance

The instance files will be added to the repository separately. The original instance-generation scripts are not available. The descriptions below document the published construction process; they are not a claim that this repository can regenerate the files.

## MOAP

The multi-objective assignment problem instances are sourced from Kirlik and Sayın (2014). The paper uses 10 subclasses with 10 instances each (100 instances). These are not described as newly generated by the authors of the tri-objective matheuristic paper.

Suggested location: `data/original/MOAP/`.

## MOKP

The multi-objective knapsack problem instances are sourced from Kirlik and Sayın (2014). The paper uses 10 subclasses with 10 instances each (100 instances).

Suggested location: `data/original/MOKP/`.

## TOFLP

The tri-objective facility-location instances are newly generated from the bi-objective single-source capacitated facility-location instances introduced by [Gadegaard et al. (2019)](https://www.sciencedirect.com/science/article/pii/S0305054823002617#b23). Total customer-demand coverage is added as the third objective (see Appendix A.3 of the paper).

The set contains 12 subclasses, with 10 instances per subclass (120 instances). The classes vary the number of facilities from 5 to 60 in increments of five; each instance has twice as many customers as facilities.

Suggested location: `data/generated/TOFLP/`.

## TOMIPLIB

The tri-objective binary integer linear programming instances are based on single-objective binary instances from [MIPLIB 2017](https://miplib.zib.de/) (Gleixner et al., 2021).

The construction described in the paper begins with 90 instances categorised as easy, meaning that a single-objective solver can solve them within one hour using default settings. The coefficients of the second and third objectives are generated by shuffling the coefficients of the original objective, following [Adelgren and Gupte (2022)](https://www.sciencedirect.com/science/article/pii/S0305054823002617#b2). The resulting tri-objective instances proved difficult; the computational study therefore retains the five instances for which Bensolve found the complete set of LB solutions within 15 minutes.

Suggested location: `data/generated/TOMIPLIB/`.

## Reproducibility note

The published descriptions establish benchmark provenance and high-level construction methodology. They do not provide the exact generation scripts, random seeds, or all implementation details needed to regenerate byte-identical files. Once uploaded, the original instance files should be treated as the authoritative computational-study data.
